COMMENT AJOUTER UN SPLASHSCREEN
================================

1. Prépare ton image et nomme-la exactement :

     splash.png

2. Dépose-la directement dans ce dossier (assets/splash/splash.png).

3. Envoie-la sur GitHub avec le reste du projet. Aucune autre
   modification n'est nécessaire : l'application détecte le fichier
   toute seule au démarrage.

   - Si le fichier est présent, il s'affiche plein écran à l'ouverture
     de l'app pendant un court instant, puis s'efface en fondu.
   - Si le fichier est absent (comme actuellement), l'app démarre
     normalement, sans aucun écran vide ni erreur.

Recommandations pour l'image :
   - Format carré ou proche du carré (ex: 1024x1024 px)
   - PNG avec fond transparent si tu veux un logo/illustration qui se
     détache, ou fond plein si tu préfères une image pleine page
   - Le fond de la page derrière l'image est un gris très clair
     (#f6f6f7) : une image avec un fond blanc ou transparent s'intègre
     mieux visuellement

Pour changer l'image plus tard, remplace simplement le fichier
splash.png par un autre (même nom).
